# EV Charging Points Data Engineering Project

## Overview
A team-based data engineering project completed as part of my
Junior Data Engineer bootcamp. The project explores EV charging
point data in Singapore and demonstrates a data pipeline from
raw data extraction and transformation through to database
storage and analysis.

## My Contributions
- Extracted and processed EV charging point data using Python
- Cleaned and transformed raw JSON data using Pandas
- Contributed to the design of database and populated database tables using PostgreSQL
- Developed SQL queries for data analysis
- Used Git and GitHub for version control and collaboration

## Technologies
Python | Pandas | PostgreSQL | SQL | Git | GitHub

## Data Pipeline
REST API Raw Data -> Python / Pandas -> Data Cleaning & Transformation -> PostgreSQL

## Key Learnings
- Working with nested JSON data
- Data cleaning and transformation
- Relational database design
- SQL querying and aggregation
- Git-based team collaboration
